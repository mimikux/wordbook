# Wordbook 私人資料保護與 GitHub 備份

這個 **Public** GitHub 專案只能存放 Wordbook App 程式碼、公開圖示、測試音檔、Apps Script 範例及去識別化的資料庫結構。

**不要上傳** 單字詞庫完整 JSON / CSV、Google Translate 收藏紀錄、個人 AI 解析、登入代碼、Supabase 管理金鑰、私人的完整 SQL 匯出等。

Wordbook 正式資料存在 **Supabase（有 Auth 與 RLS）**。GitHub Pages 靜態檔案本身不提供存取權限保護，Public Repository 中的內容和歷史版本其他人都可以讀取。

### 現有資料狀況（2026-10-17）

- Supabase 雲端：32 筆（其中 31 筆有進階說明）。
- 舊版 Android 下載 HTML：約 893 筆（含個人修改、刪除紀錄），尚未確認完成遷移。
- 在 Wordbook 已登入後可用「⋯ → 載入／合併舊版備份 → **合併**」將最新舊版 JSON 整理進 Supabase；不要選「整本取代」，以免失去現在已建的 31 筆 AI 解析。
- 匯入完確認詞數及修改後，建議在 Wordbook 匯出完整 JSON 備份，存在個人 Google Drive 或獨立的 **Private** GitHub repository。
- 若一定要使用 GitHub 保存私人詞庫，應另建 `wordbook-private-backup`（Private）儲存庫，絕不放進目前的 Public `wordbook`。如需定期備份，應另設安全的備份流程與可撤銷權限。

**注意：** GitHub 的 Private 分支或 Private Issue，無法讓 Public repository 的資料真正保密。
